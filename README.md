# SUURUU — Recorrido de proyecto

Landing del recorrido de proyecto de SUURUU, construida a partir del screenset.

El contenido (página, imágenes y tipografías) está cifrado con AES-256-GCM dentro de `index.html`;
se abre en el navegador con la contraseña del proyecto. Sin ella, el archivo no revela nada.

Para publicarla: Settings → Pages → Deploy from branch → `main` / root.
